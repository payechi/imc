# IMC Website

A responsive website for a coaching center, built with Next.js.

## Run locally

Requirements: Node.js 20.9 or later and npm.

```bash
git clone https://github.com/payechi/imc.git
cd imc
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

To create and run a production build:

```bash
npm run build
npm run start
```
